# Product Requirements Document — AI Gold Institutional Tutor

## 1. Product vision
Create an interactive education and review platform for traders learning the Gold Institutional Trading methodology.

## 2. Target users
- Beginner-to-intermediate XAUUSD traders learning structured market context.
- Traders who understand setups but enter too early, chase, or mismanage risk.
- Advanced learners who want screenshot-based review, journaling, and repeatable scoring.

## 3. Primary jobs to be done
### Learn
Progress through a structured course from gold-market foundations to institutional session analysis, entry quality, behaviour and review.

### Ask
Use an AI tutor to explain terminology, concepts, scenario logic and course material.

### Review
Upload H1/M30/M15/M5/M1 screenshots and receive structured evidence-based analysis.

### Score
Receive an Entry Quality score and Behaviour score independent of trade outcome.

### Journal
Save plan, screenshots, review, scores, P&L, MFE/MAE, diagnosis and corrective action.

### Practice
Complete chart drills, blind reviews and archetype classification exercises.

### Improve
Detect repeated behavioural and execution errors and prescribe one measurable change.

## 4. Core learning model
1. Market context
2. Session classification
3. Trade thesis
4. Liquidity event
5. M5 confirmation
6. Retest
7. M1 precision execution
8. Risk and management
9. Post-trade review

## 5. New York classification
The tutor classifies the session as:
- Pullback
- Continuation
- Reversal
- Sideways

Classification is descriptive and **not scored**.

## 6. Entry Quality Score
| Component | Points |
| --- | ---: |
| Location Quality | 20 |
| Liquidity Event | 20 |
| M5 Structure / Displacement | 20 |
| Retest Quality | 15 |
| VWAP / Volume Profile / Pivot Confluence | 10 |
| Momentum / TDI Confirmation | 10 |
| Entry Efficiency / Structural SL | 5 |
| **Total** | **100** |

Bands:
- 90–100: A+
- 80–89: A
- 70–79: B
- <70: No-Trade Quality

Hard gates prevent weak indicator confluence from manufacturing an A+ score.

## 7. Behaviour Score
Five 20-point categories:
- Pre-entry discipline
- Trigger discipline
- Risk discipline
- Management discipline
- Emotional discipline

Behaviour tags include FOMO, Chase, Early Entry, Late Entry, Moved SL, Oversized, Early Exit, Overtraded, Revenge Trade, Added to Loser, Ignored Classification, Ignored Liquidity, Patient, Waited for Retest, Excellent Execution.

## 8. Visual Trade Review
Required evidence package:
- H1 when context requires it
- M30
- M15
- M5
- M1

Review sequence:
Screenshots → NY Classification → Thesis → Entry Quality Score → Behaviour Score → Outcome → Diagnosis → Corrective Action

Blind review should be supported so setup quality can be scored before P&L is revealed.

## 12. Funnel
Short-form content → DM keyword → diagnostic question → Value Bomb → AI Tutor/free lesson → Course → visual-review/journal membership

## 13. MVP acceptance criteria
- Authenticated user can access course lessons.
- User can chat with tutor against curated knowledge.
- User can upload screenshots with timeframe/session metadata.
- Tutor returns structured evidence and Entry Quality component scores.
- Component totals validate to 100.
- User can save a review to journal.
- Behaviour score and tags can be recorded.
- User can view prior reviews and trends.
- Content resources can route users to related lessons/tutor workflows.
- Missing evidence is explicitly surfaced rather than inferred.

## 14. Non-goals for MVP
- Automated broker execution
- Guaranteed trade calls
- Fully autonomous live trading
- Real-time portfolio management
- Unreviewed personalized financial advice

## 15. Success metrics
- Course completion
- Quiz accuracy
- Classification accuracy
- Human/AI review agreement
- Entry-score consistency
- Reduction in repeated behaviour errors
- Entry score vs MFE/MAE/expectancy
- Value Bomb requests
- Tutor activation
- Qualified DM conversations
- Retention
