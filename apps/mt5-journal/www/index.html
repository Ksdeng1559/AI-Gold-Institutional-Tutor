RUN WITH YOUR ACTUAL MT5 ACCOUNT

Start the local application

The hosted interface accepts files. To read MT5 directly, run this same application on the computer where MT5 is running.

  1. Download the application from the GitHub proposal branch.
  2. Enable MT5's internal MCP server and set its regenerated key in the private MT5_MCP_TOKEN environment variable. Prefer investor/read-only account access.
  3. Run python apps/mt5-journal/server.py from the repository folder.
  4. Open http://127.0.0.1:8088 and select Connect local MT5.
Application and setup instructions ↗

The key stays on the local service. Keep the service on loopback. Reviews save in a local SQLite database; trade snapshots remain in tab memory until you save or download a review. This release does not poll in the background.
